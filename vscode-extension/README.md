# Local Coding Agent — VS Code extension

Chat with a fully offline coding agent (Ollama + RAG + LangGraph):

- **Ask** about your project (answers cite source files)
- **Edit** the open file — the change appears as a proposal card with diff,
  checker result and **Accept / Reject**
- **Review** the open file against your coding standard (add it with **@ Context**)
- Pick or install Ollama models from the chat; start/stop the local server

Requires the Python agent server from the main repository:
https://github.com/Harshadcse/local-coding-agent — see its README for setup.
